# 🚀 AI Ads Generator

AI Ads Generator is a full-stack web application designed to help users create AI-powered advertisements quickly and efficiently. The platform provides a simple dashboard where users can generate, manage, and export advertising content using AI integration.

---

## ✨ Features

* 🔐 Secure user authentication system
* 🤖 AI-powered ad generation
* 📊 User dashboard and management panel
* 🕘 Ads history tracking
* 📁 Export generated advertisements
* 📱 Responsive and modern interface
* ⚡ Fast and lightweight backend architecture

---

### Backend

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/oderdare-star/ai-ads-generator.git
```

2. Move the project folder to:

```bash
xampp/htdocs/
```

3. Start Apache and MySQL using XAMPP

4. Import the database file into phpMyAdmin

5. Open the project in your browser

```bash
http://localhost/ai-ads-generator
```
